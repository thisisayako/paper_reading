## 背景・目的

数十年にわたる複数分野の研究が、男性のほうが女性より多く論文を出版することを示してきた（生産性パズル）。しかしその理由と帰結は不確実。原文が列挙する説明は次のとおり。

- 女性が下位・低生産性の機関に採用されること
- 教育・サービス負担がより重いこと
- 研究またはタスクの専門化の差
- 初期成果の草稿作成により多くの時間を投じること
- キャリア長が短いこと
- 出産・育児（parenthood）の影響がより大きいこと

これらのうち、親になることは男女双方の教員の過半数に生じるが、その科学的生産性への効果に関する研究は矛盾しており、負（原文引用14–16）、正（17）、無関係（11, 18, 19）が併存する。COVID-19以降、この論点への注目が高まり、初期の結果は女性の生産性損失と家事労働の増加をより大きく示した。因果的効果の確立が困難だったのは、研究がキャリア年齢、縦断的生産性、親になった時点、変化する社会規範のいずれかの詳細情報を欠くため。

親になることがキャリアを変えうる経路（原文の整理）

1. 時間配分：育児への時間需要が新たに生じ、出産した母親には産後回復の必要も生じる。アカデミアの女性は男性より家事・育児時間が長いと報告
2. 時間の配分先の性差：親になると男女とも労働時間を減らしうるが、その減らし方がジェンダー化されている。父親はしばしばキャリア昇進により重要な研究時間を守り、母親はしばしば教育（teaching）を守る（原文引用24）。したがって、親になることは女性の研究可能時間を男性より大きく減らしうる
3. 選好の変化：親であることとキャリア昇進の両立を望む教員にとって、子を持つことは、両立達成のためにより生産的・組織的になる動機となりうる
4. 自己選抜：女性は学界を親に対して非友好的と認識しやすく、学界外のキャリアを選ぶ傾向。これが教員集団の構成そのものを形づくる

中心的な問い：早期キャリアの教員のうち、親になった者とならなかった者の生産性ギャップはどれだけか。そして親になることの効果は男女でどう異なるか。特に第一子の誕生前後において、ジェンダー役割と親状態がどう交差してアカデミックキャリアを形づくるか。

分野選択の論理：計算機科学・歴史学・経営学の3分野は、女性比率と学術的慣行の多様性から選ばれた。テニュアトラック教員に占める女性は計算機科学で15%、歴史学で37%。共同研究率と評価される出版形態も異なる。歴史学の教員は共著者がいてもごく少数の書籍・モノグラフを書き、計算機科学の教員は多数の共著者とともに査読付き会議録に発表する。

## 方法

- 調査：2017年夏〜2018年秋。米国・カナダの博士号授与部局の公開オンライン名簿から氏名とメールアドレスを収集し、招待メールを送付
  - 送付先：計算機科学 5,792人、経営学 9,573人、歴史学 4,336人（合計 19,701人）
  - 部局数：計算機科学 205、経営学 112、歴史学 144（Materials and Methods）
  - 回答：3,064人（15.6%）（要約者検算：3,064 / 19,701 = 15.55%、整合）
  - 招待状は親であることに言及せず、親に関する設問は多数の設問のうちの数問（需要側の応答バイアスを抑える設計）
  - 著者は「女性のほうがやや回答しやすかったが、教員ランクと部局威信については代表的な標本」と主張
- 出版データ：100,972本の論文（要約者検算：79,274 + 15,352 + 6,346 = 100,972、整合）
  - 計算機科学：DBLP（https://dblp.uni-trier.de）とのリンク。DBLPのカバレッジが時間変動するため、およびCS全体の出版率上昇（図S1）を考慮して、2つの線形調整（time-adjustment）を出版数に適用
  - 歴史学・経営学：回答者のCVから手作業でカウント
  - リンクできた教員数：計算機科学 1,061人、経営学 525人、歴史学 294人（合計 1,880人）
- 育児休業政策データ：各機関の制度（section SC、原文引用50）
- 主要変数
  - アウトカム：年間出版数（`Y_{i,t}`）。累積生産性の分析では、第一子誕生（または初回助教就任）を基準とした相対年で集計
  - 処置：親になったこと。`T_i = 1` が親（treatment）、`0` が反実仮想の親（control）
  - 統制：機関威信（`Π_i`）
- 研究デザイン・推定方法
  - マッチング：同一分野・同一性別・同一生年の親と非親を対応づけ、非親に反実仮想の第一子誕生年を割り当てる。反実仮想イベントの時点は、親の性別・生年・分野で層別した経験的な「親になる年齢」分布から抽出（原文引用41 = Kleven, Landais & Søgaard 2019）
  - CITS（comparative interrupted time series、比較つき中断時系列）。原文の式(1)：

    `Y_{i,t} = β0 + β1·t + β2·I[t>0] + β3·t×I[t>0] + β4·T_i + β5·T_i×t + β6·T_i×I[t>0] + β7·T_i×I[t>0]×t + β8·Π_i`

    `t` は第一子誕生からの相対年。関心のある係数は β6（親になった直後の生産性の水準変化。親になる前の水準を統制し、非親群の趨勢を考慮したもの）。図2に示される値は `β6 / Ŷ0`（当該群の期待生産性に対する比率）
  - CITSは出生が雇用・賃金に与える影響の研究（原文引用39, 40）で用いられてきたが、アカデミックキャリアへの適用は本論文が初めてと著者は主張
  - マッチングの妥当性検証：親と反実仮想の親は、イベント前の生物学的年齢・キャリア年齢・機関威信について統計的に類似（表S6、未入手）
  - 代替手法：section SD で非パラメトリック・マッチングの2つの代替を検討（未入手）

## 結果・考察

### 全体の結果・考察

要旨。 3分野の早期キャリア教員において、初回助教就任の5年前から10年後までの累積出版数の男女差は計算機科学 11.9本・経営学 3.1本・歴史学 2.5本であり、子のない者に限るとそれぞれ 5.2本・0.8本・1.5本まで縮む。この縮小の内訳を年次データで追うと、CITSの推定する親になった直後の水準変化は母親で計算機科学 −17.32%・経営学 −23.54%・歴史学 −48.25% と一貫して負、父親では歴史学 −19.32%・経営学 +11.72% と符号が揃わない。一方で回答者自身の生産性目標（表1のAim）は子の有無で有意に変わらず（計算機科学の女性 8.2本 対 9.2本、t = −0.95, P = 0.35）、他者への期待だけが子のある女性について選択的に下がる。育児休業は母親の91.8%が取得し父親は62.1%（z = 9.24, P < 10⁻¹⁹）、職選択で育休制度を重視するのは女性45.9% 対 男性20.6%（χ² = 141.81, P < 10⁻³⁰）だが、機関の威信を重視する程度には男女差がない。2000年以後に親になったコホートでは母父ギャップが計算機科学 27.3本→9.9本、経営学 3.4本→−1.5本、歴史学 4.4本→2.9本と縮小している。

結果間の整合・不整合と位置づけ。 中心的主張を担うのは図1と図2の組み合わせであり、この2つが揃って初めて「累積ギャップの相当部分が、出産直後に集中する母親の生産性低下から生じる」という主張が成立する。図1単独では、子のある者とない者の差が親になったことの帰結なのか、もともと生産性の異なる者が親になっているのかを区別できず、図2単独では年次の水準変化が10年累積のギャップにどれだけ寄与するかを語れない。記述統計は土台（親比率78.7%、平均33歳、親と非親で所属威信に差なし＝D = 0.03, P = 0.59）であって主張そのものではなく、図3・表1は機構（理想的労働者規範と育休制度）に関する補助、図4は射程の拡張と政策的含意で証拠の階梯の最外周。結果間の緊張は7件。（1）最も重大なのは、考察部が「ギャップの大半（87.6〜95.6%）が親効果による」と書く箇所で、この数値は結果部で定義された出版数の比であり、性別ギャップの分解比ではない。図1の値から素直に分解すると親効果に帰属する割合は計算機科学 56.3%・経営学 74.2%・歴史学 40.0% であり、歴史学では大半ではない。すなわち抄録の主張を支える数量が、本文の図から再現できない。（2）「父親には概して効果がない」という本文の記述は、図2Bに印字された父親 +11.72% と整合しない。（3）図2・図4の効果量に信頼区間・標準誤差がなく、反実仮想の出産時点を経験分布から確率的に抽出している以上その抽出のばらつきを含む不確実性が評価できない。歴史学の t = 68.8 は他のt値がすべて1〜7の範囲であることと桁が異なる。（4）表1の「子なし」群が10歳超の子をもつ親を含むため、「親であることは自身の目標を変えない」という結論は親効果を過小に見せる比較群の汚染の上に立つ。（5）イベント前に親と非親の生産性水準が有意に異なる（t = 4.89, 4.47）事実を、著者は式(1)の β4・β5 で統制済みとしながら同時に選択効果の証拠としても用いており、同じ事実が2つの役割を兼ねている。（6）著者は「現職教員に限定された標本ゆえ推定値は下限」という生存者バイアスの留保を親効果には適用しながら、図4の縮小トレンドには適用していない。（7）計算機科学の母父差に 13.1本・17.6本・9.9本・5.4本の4値が現れ、うち 9.9本（図4A）と 5.4本（表S5）はどちらも2000年以後を指すのに窓の定義が説明されていない。

全体を通じた著者の解釈。 生産性ギャップが完全にジェンダー化された親効果に起因するなら子のない男女の趨勢は区別できないはずで、実際には小さな差（4.4〜12.4%）が残る。それでも親であることこそが主要因であり、その作用は母親の短期生産性の急落を通じて生じる。親であること自体は生産性を下げるのではなく（親のほうが非親よりやや生産的）、ジェンダー化された時間配分がペナルティを生む。母父ギャップは時代とともに縮小しており、それは男性が生産性を落としたためではなく女性が上げたためで、共同研究率の上昇と有給・性別中立的な育休制度の普及を反映している可能性がある。観測される効果は、生産性損失の大きい者が標本に入る前に学界を離脱するため真の効果の下限である。

全体を通じた要約者の解釈と注意点。 頑健なのは定性的なパターン、すなわち母親ペナルティが第一子誕生の前後に集中し、3分野すべてで符号が負であり、かつイベント前の水準・趨勢を統制してなお現れるという構造である。脆いのは分解の数量（87.6〜95.6% は量の取り違え、正しく分解すると 40.0〜74.2%）と時系列の縮小（生存者バイアスの留保が非適用、信頼区間なし、経営学の −1.5本は n = 366 の1点推定）。したがって本論文は「アカデミアにおける母親ペナルティの存在と、その短期集中的な性質」の証拠として引用すべきであり、抄録の "Parenthood explains most of the gender productivity gap" をそのまま引いてはならない。また本論文が最も示唆的な発見である「願望と実績の乖離が母親で選択的に大きい」を定量化していない点も、引用時に補われるべき空白である。因果的識別については、マッチングが生年・分野・性別のみで行われ、婚姻状態・パートナーの職業・世帯所得が一切統制されていない以上、著者自身の限界の記載どおり、推定されているのは記述的な関連であって因果効果ではない。

### 親になることの記述統計

結果。

- 40歳以上の教員のうち 78.7% が子を持つと回答。女性 71.0%、男性 82.2%（z = 6.00, P < 10⁻⁸）
- 男女とも平均 33歳で親になる（t = −1.04, P = 0.30）。一方、米国一般人口の平均は男性31歳、女性26歳（原文引用36, 37）。教員、とくに女性は親になる時期を遅らせている
- 親になる年齢は緩やかに上昇している（図S2、未入手）
- 親になる年齢と現所属機関の威信の相関は弱く、機関ランクが100位改善すると1年だけ遅れる（β = −0.01, t = −2.73, P = 0.01）
- 親と非親の間で、所属先の威信に有意差なし（Kolmogorov-Smirnov検定, D = 0.03, P = 0.59）
- 39.5% の教員が最初の教員職に就く前に親になっている
- 母親は父親より子の数が少ない（平均 1.8人 対 2.2人、t = 7.17, P < 10⁻¹¹）

原文内部の不整合（両論併記）。

1. 部局数：抄録・序論はいずれも「450の博士号授与部局」と記すが、Materials and Methods の内訳は 205 + 112 + 144 = 461。11部局の差。原文は説明していない。両方の値を記録する。
2. 最初の教員職の前に親になった教員の割合：結果部（p.2）では「39.5%」、考察部（p.5）では「39.4%」。同一の量に対して異なる値。
3. 出版データにリンクできた教員数（1,880人）と図1の N（1,006 + 491 + 285 = 1,782人）が一致しない。 差は98人。図1の分析には親になった時点の情報も必要であり、その欠測による減少と推測されるが、原文に説明はなく、要約者はこれを断定しない。

考察（要約者）。 教員の平均親年齢33歳と、米国一般人口の「男性31歳・女性26歳」の比較は、出典（原文引用36, 37）が測っている量が同一でない可能性がある。引用37（Khandwala et al. 2017）は1972–2015年の全出生1億6,886万件を分析した「父親の年齢」であり、第一子に限定していない可能性が高い。第一子出生時年齢と全出生の平均父親年齢は前者のほうが低くなる。この比較は要確認事項。

### 図1：男女の累積生産性（分野別）

図1のN：計算機科学 1,006人、経営学 491人、歴史学 285人。網掛けは平均のブートストラップ区間。

| 分野 | 全体（Total） | 子のない者（inset） | 親（本文） |
|---|---|---|---|
| 計算機科学 | 11.9 | 5.2 | 13.1 |
| 経営学 | 3.1 | 0.8 | 3.5 |
| 歴史学 | 2.5 | 1.5 | 3.1 |

（要約者注：「全体」は図1の主パネルの数値ラベル、「子のない者」は inset のラベル。「親」の値は本文にのみ記載され、図1には印字されていない）

原文の記述：

- 「子のない女性は、子のない男性の総出版数の平均 87.6〜95.6% を産出する。残差（4.4〜12.4%）は、キャリア年齢と親であることでは説明されないままであり、本調査の対象であるテニュアトラック教員（博士号授与部局）にのみ当てはまる」
- 「親のなかでは、母親は父親より 13.1本、3.5本、3.1本少なく産出（73.6〜82.9%）。このより大きなギャップは、親であることに伴うジェンダー差が教員の生産性に大きな効果をもつことを含意する」

考察（著者）。 生産性ギャップが完全にジェンダー化された親効果に起因するなら、子のない男女の生産性趨勢は区別できないはず。実際には子のない者の間にも小さな差が残る。

要約者による最重要の指摘：考察部の「87.6〜95.6%」の使い方は誤り。

結果部での「87.6〜95.6%」は、子のない女性の出版数が子のない男性の何%にあたるか（出版数の比）である。ところが考察部（p.4末尾〜p.5冒頭）は次のように書く。

> "the majority of the extant gap (between 87.6 and 95.6%) is caused by a gendered effect of parenthood"
> （既存のギャップの大半（87.6〜95.6%）は、ジェンダー化された親効果によって引き起こされている）

これは「男性の出版数に対する比率」を「性別ギャップのうち親効果で説明される割合」に読み替えたものであり、量の取り違え。残差 4.4〜12.4% は「男性の総出版数に対する割合」であって「性別ギャップに対する割合」ではない。

要約者が図1の数値から素直に分解すると、性別ギャップのうち親であることに帰属する割合は次のとおり。

| 分野 | 全体のギャップ (a) | 子のない者のギャップ (b) | 親効果に帰属する割合 (a−b)/a |

原文内部の不整合（両論併記）。

1. 本文は経営学の父親の効果（+11.72%）に言及していない。 「父親には概して効果がなく、歴史学が唯一の例外」という記述は、図2Bに明示的に印字された `Men with and without children: 11.72%` と整合しない。さらに考察の直前（p.3）で著者は「父親に短期的な生産性上昇が生じるという明確な証拠は見出せない（we also find no clear evidence that parenthood causes a short-term productivity increase for fathers）」と書くが、図2Bはまさにその上昇（+11.72%）を数値ラベルとして示している。図2Bの値が有意でないなら本文でそう明記すべきであり、有意なら本文の記述が誤り。原文からは判定不能。両方を記録する。

長期効果。 「長期の出版率が親であることの影響を受けるかについて、我々の結果は決定的でない（inconclusive）」。式(1)の β7（イベント後の傾きの変化）は本文に報告されていない。

下限としての推定値。 親であることが、標本に観測される前に個人を学界から離脱させうる（生産性損失が大きい者ほど離脱しやすい選択効果）ため、これらの推定値は真の効果量の下限である可能性が高いと著者は主張。

考察（要約者）。

1. イベント前に親と非親の生産性水準が有意に異なる（t = 4.89, 4.47）ことは、統制群の妥当性に関する重大な情報。 CITSの式(1)は `β4·T_i`（水準差）と `β5·T_i×t`（趨勢差）でこれを吸収する設計になっているため、水準差そのものは致命的でない。しかし著者はこの差を「選択効果の証拠」として同時に用いており、同じ事実が「モデルで統制済み」と「未観測の選択の証拠」の両方に使われている。前者が正しいなら後者は残差選択の話に限定されるべき
2. CITSの識別仮定は「非親群の趨勢が、親になった者が親にならなかった場合の反実仮想を表す」こと。 著者自身が Materials and Methods でこの仮定が「完全には真でないかもしれない」と明記している。マッチングは生年・分野・性別のみで行われ、婚姻状態・パートナーの職業・世帯所得は一切マッチングされていない（著者もこれを潜在的交絡として挙げる）
3. 反実仮想の出産時点は経験分布から確率的に抽出されている。 この抽出のばらつきが推定値の不確実性に与える影響（複数回抽出したときの推定値の分散）が本文に報告されていない。図2に信頼区間が示されていないことは、`β6/Ŷ0` の精度を評価できないことを意味する。「−48.25%」という値を、±どれだけの不確実性を伴うのかを示さずに引用すべきでない。
4. 共同研究率との相関は3点（分野3つ）に基づく。n = 3 の相関に統計的な意味はない。 著者が「因果的とは言えない」と留保しているのは適切だが、それでも「相関がある」と述べるには根拠が薄い
5. 歴史学の母親の −48.25% は、母数の小ささ（図1CのN = 285、うち母親は一部）を考えると極めて不安定な推定値の可能性がある

## 主張の限界・残された課題

### 著者が記載した限界

- 無作為割当がない観察研究であり、因果推論手法を用いた推定にはただし書きが伴う
- マッチングは、教員が親になる年を説明しうる未観測の交絡変数が存在しないことを仮定する。 考えられる交絡には、婚姻・交際状態とその性差（原文引用65）が含まれる
- CITSは、非親コホートが「親にならなかった場合の親」の適切な統制群であることに依拠する。この仮定は完全には真でないかもしれない

## 修士論文への示唆

1. 本論文はKAKEN分析にとって「最も直接的な理論的テンプレート」であると同時に、「KAKENでは測れないものの明示」でもある。

Cech & Blair-Loy 2019 と本論文は、いずれも男女の生産性・キャリア格差の主要因として出産・育児を特定する。両者が正しければ、KAKENで観測される男女の資金獲得格差は、審査バイアスの効果と親効果の合成であり、KAKENデータ単独では分離できない。この事実は修論の「限界」ではなく、研究デザインの出発点として書くべき。

2. CITS（比較つき中断時系列）をKAKENに移植する具体案。

本論文の式(1)は、KAKENの縦断構造にそのまま移植できる。ただし「第一子誕生」に相当する観測可能なイベントが必要。候補は3つ。

- (a) 科研費の研究中断・期間延長制度の記録。 科研費には、産前産後休暇・育児休業を理由とする研究中断（および研究期間の延長）の制度がある。KAKENデータの `研究期間 (年度)` に延長が反映されているか、また中断の事実が記録されているかを最優先で確認する。記録されていれば、これが日本のアカデミアにおける出産イベントの直接的かつ行政データ由来の代理変数となり、本論文が調査（回答率15.6%）に頼らざるを得なかった弱点を克服できる。これはKAKENデータを用いた研究の最大の潜在的貢献になりうる
- (b) 「研究成果の空白年」。 中断が記録されていない場合、女性研究者の課題実施年度のうち、報告書の提出がない年・課題数が急減する年を検出する。ただし偽陽性が多い
- (c) 反実仮想イベントの確率的割り当て。 イベントが観測できない場合、本論文と同様に、日本の女性研究者の第一子出生年齢分布（人口動態統計・「科学技術系専門職における女性活用に関する調査」等の外部統計）から、性別・生年（初回採択年度で代理）・分野で層別してイベント時点を抽出する。この場合、推定されるのは intention-to-treat 的に希釈された効果であり、出産しない女性を含むため過小評価となることを明記する

3. アウトカムを「論文数」から「科研費の獲得」へ置き換える際の設計。

本論文の `Y_{i,t}` = 年間出版数 に対応するKAKENのアウトカムは複数ありうる。単一のアウトカムに絞らず、以下を並列に推定する。

| 本論文のアウトカム | KAKENでの対応 | 備考 |
|---|---|---|
| 年間出版数 | 年間の新規採択件数 | 出版と資金は同一ではない |
| 累積出版数 | 累積の配分額（実質化） | 種目により金額規模が桁違い |
| — | 保有課題数 | Hechtman 2018 の「年間平均保有プロジェクト数」に対応 |
| — | 研究種目の階梯（若手→基盤C→基盤B→基盤A） | 「昇進」に相当。Kaminski 2012 の准教授昇進率に対応 |
| — | 科研費プールからの退出 | Hechtman 2018・Kaminski 2012 の生存分析に対応 |

注意：KAKENの `研究期間` は複数年度にわたるため、「年間の新規採択件数」はゼロが大半を占める疎なカウントになる。ポアソン／負の二項回帰、あるいは「その年度に何らかの課題を保有していたか」の二値化を検討する。

4. 「短期効果は大きいが長期効果は不明」という本論文の構造を、そのまま仮説にする。

本論文の最も頑健な発見は、母親ペナルティが出産直後の数年に集中し、長期の出版率への影響は決定的でない（inconclusive）ということ。KAKENで検証可能な対応する仮説：

- H1：女性研究者の科研費新規採択確率は、出産（またはその代理イベント）の直後2〜3年に選択的に低下する
- H2：この低下は、より長い時間軸（5年以上）では回復する
- H3：低下の大きさは、共同研究の程度が低い分野（＝研究分担者数が少ない課題が多い分野）で大きい（本論文の「共同研究率と母親ペナルティの逆相関」の検証）

H3 は KAKEN データで直接検証できる。 KAKENには研究代表者だけでなく研究分担者の情報があり、分野ごとの平均分担者数を「共同研究率」の代理として算出できる。本論文が n = 3 の相関でしか示せなかった仮説を、数十の中区分で検証できる。これは修論の明確な貢献になりうる。

5. 本論文の誤り（「87.6〜95.6%」）から学ぶ、分解の書き方。

修論で「男女差のうち X% が要因 Z で説明される」と書く場合、必ず次を明示する。

- 分母が何か。 「男性の平均値に対する割合」なのか「男女差そのものに対する割合」なのか
- 分解の方法。 Oaxaca-Blinder分解を用いるなら、説明部分（endowment effect）と未説明部分（coefficient effect）を分けて報告する。単純な差の引き算（本論文がやっていること）なら、その旨を書く
- 構成効果の扱い。 本論文の分解が粗いのは、親になる割合が男女で異なる（女性71.0%、男性82.2%）ことを無視しているため。KAKENでも、種目・分野の構成が男女で異なるため、単純な全体採択率の比較は構成効果を含む。採択率の男女差を報告するときは、必ず種目・分野・年度を統制した値と、統制しない粗い値の両方を示す

6. 「願望と実績の乖離」という測定可能な概念。

本論文の表1が示す最も興味深い構造は、母親は自身の生産性目標を下げていないのに、実際の生産性だけが下がるという点（ただし表1の「子なし」群が年長児の親を含む汚染に注意）。KAKENの対応物として、

- 申請行動（願望）と採択（実績）の分離。 KAKENは採択課題のみを収録し、不採択申請を含まない。したがって「申請したが採択されなかった」ケースを観測できない。これはKAKENデータの決定的制約であり、Hechtman 2018 が NIH 内部データで区別できた「申請件数の差」と「採択率の差」を、KAKENでは区別できない
- 代替策：科研費の年次公表資料（日本学術振興会「科学研究費助成事業の配分について」）には、種目別・性別の申請件数と採択件数が集計値として公表されている年度がある。個票では不可能な申請/採択の分離を、集計レベルで行える可能性がある。要確認事項として最優先で調査する価値がある

7. 注意すべきバイアス（要約）。

- 生存者バイアス：本論文の標本は「現職教員」。KAKENの分析対象は「科研費を1度でも獲得した研究者」であり、同型の選抜を受けている。科研費を一度も獲得しなかった研究者（女性に偏る可能性）はデータに存在しない。 推定される男女差は、この強い選抜を通過した者の条件付き比較であり、真の効果の下限である（本論文と同じ論理）
- 統制群の妥当性：CITSは「非親（＝反実仮想の親）」が適切な統制群であることを仮定する。KAKENで反実仮想イベントを割り当てる場合、マッチングに使える変数は分野・初回採択年度・所属機関威信に限られ、婚姻状態・パートナーの職業は一切観測できない。本論文の著者自身が、パートナーの職業が父親と母親のペナルティ差を説明しうると述べている以上、この未観測交絡は決定的。修論では「親効果の因果的推定は不可能であり、記述的な関連の推定にとどまる」と明記する
- 効果量の不確実性の提示：本論文は点推定値のみを示し信頼区間を示さない。修論では、すべての効果量に 95%信頼区間を併記する（CLAUDE.md 行動ルール3・14）
- アウトカムの質：「論文数」と同様に「科研費の採択件数」も質を測らない。配分額と種目階梯を併用することで部分的に補える
